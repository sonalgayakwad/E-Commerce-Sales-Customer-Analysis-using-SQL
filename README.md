# E-Commerce Sales & Customer Analysis using SQL

## Project Overview
This project analyzes e-commerce sales and customer data using SQL queries to identify sales trends, customer behavior, and business insights.

## Objectives
- Analyze overall sales performance
- Understand customer purchasing behavior
- Identify top-selling products
- Analyze sales by category
- Generate useful business insights using SQL

## Tools & Technologies
- MySQL
- SQL

## SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- Aggregate Functions
- Subqueries

## Project File
- Ecommerce_sales_customer_analysis.sql – Contains the database queries used for analysis.
